# Running The Last Screen Standing

For whoever is hosting the night, not writing the code. Everything below is
what actually happens on screen — nothing here needs reading aloud, because
the game narrates itself.

## Before you open the lobby

Everyone joins from their own device. There is no shared screen, so no
screen-share setup — just get the room code to people (`survival` shows it
large in the lobby) and let them type it in.

Two lobby-only toggles sit above "Begin the briefing," and both lock the
moment you tap it:

- **Playing solo / Playing in teams.** Teams (the default) split the room
  into groups of 3–4 who answer together — whoever taps first locks the
  move in for the whole team, and the four extraction puzzles are dealt
  across teams so no single team can solve one alone. Solo drops all of
  that: everyone answers, and is scored, alone. Use solo for a small group
  where you want nine individual conversations rather than a negotiation;
  use teams for anything bigger, or when the point of the night is getting
  people who don't usually work together to talk.
- **Ruthless cutoff on / off.** Five dark picks disqualify a player from a
  seat, however good their run otherwise was. This is the sharpest thing in
  the game and it's built to stay — leave it on unless you already know the
  room and think a real disqualification would land badly. Turning it off
  never hides anything: the tally of dark picks still shows at the end, it
  just stops costing anyone a seat.

Both are host-only and both disappear at "Begin the briefing" — decide them
first.

## Timing

The host console carries a running "N of M min" line once the briefing
starts, with an ahead / on-time / behind reading. It gives you five minutes
of grace before it says anything, on purpose — a host nagged from minute one
stops reading it at all.

The plan, door to door, for a room of eight:

| Phase | Minutes |
|---|---|
| Lobby | 5 |
| Briefing | 3 |
| The two warm-ups | 3 (1.5 each) |
| The nine questions | 27 (3 each) |
| The final plea | 4 |
| The tribunal | 2 |
| Result | 1 |
| **Total** | **~45** |

Bigger rooms are promised more time — the target stretches from 45 minutes
at 8 players or fewer up to about an hour at 23 or more, so "behind" reads
against the room you actually have, not a flat 45.

**When it says behind:** stop letting a reveal breathe. Read the outcomes,
let the room react for a beat, move on. The reveal button itself will tell
you if you're waiting on stragglers — "Open without 2 choices" — and opening
without everyone is fine; whoever hasn't answered is handed the round's
worst option, which is a real cost, not a shortcut you're giving them.

## Beat by beat

**Lobby → Briefing.** Tap **Begin the briefing**. If you're in teams, this is
the moment teams are actually drawn — anyone who joins after this point still
gets folded into whichever team is smallest, but the room's shape is set now.

**Briefing.** The scenario and the extraction-code rule both play as
on-screen narration — tap through it, or let it sit, nobody needs it read
aloud. Tap **Start the warm-up** (or **Start question 1** if there are no
warm-ups) once the room has actually read it.

**Two warm-ups — "First Move," "The Group Chat."** Zero stakes, just getting
everyone used to tapping and seeing a reveal. Move through these quickly.

**Nine questions.** Each one plays its own narration and clip, then five
identical-looking buttons — the choice itself is never signposted as safer
or darker by how it looks. Some rounds also carry one line from the port's
manifest, read or ask-shown depending on the round; a subset of those lines
are one of four green berths' fragments, which feed the ledger below rather
than being read straight off the screen. When enough of the room has
answered, tap **Open the outcomes** — every device opens the same full
reveal at once, all five outcomes and everyone's name against what they
picked. That's the moment worth pausing on; it's the only place all night a
choice and a name sit next to each other before the tribunal. Then **Question
N**.

**The ledger, running underneath.** From whichever round first opens a green
berth onward, players see a standing tab for it — not a separate phase, so
it never blocks you from moving the questions along. Once a berth opens it
stays open for the rest of the night, so there's no rush to trade it away
in the round it appears — but nobody solves one alone, so it only ever
opens by people actually talking to each other. A fragment is useless kept
to yourself; publishing it (**Publish it to the ledger**) is one tap.
Nobody needs to speak to use it: asking for a berth is also one tap (**I
need berth N**), and the board itself says who's still asking.

**The final plea.** Tap **The final plea** after question nine. Each player
gets a private recap of their own night, then two tries at the keypad if
they think they have the code, then — win or lose that — a 150-character
argument for why it should be them. There's no lockout for a wrong guess,
just a few seconds' cooldown, so nobody is stuck at a locked door while the
room waits.

**The tribunal.** Tap **Open the tribunal** once pleas are in (or with some
missing — same tradeoff as a reveal). The room votes. Tap **Count the
votes**.

**Result.** The board names who got out and by which of three paths — the
code, the best run of numbers, or the room's own vote — and says plainly
when a path went unclaimed: nobody solving the code is the room's own
outcome, not a detail. The night's actual extraction code is read out here
too, the one thing that was true the whole time and nobody was ever shown
directly.

## Running the debrief

A "Talk it out" section appears on the result screen automatically — you
don't write this or read from a script. It's built from what this specific
room actually did: which round split hardest, which one everyone agreed on,
which team carried the most dark picks together, who fed the ledger the
most. Up to five prompts, never the same room twice.

Treat each line as a conversation opener, not something to read verbatim —
it names a fact ("no more than 3 of 5 of you landed on the same call") and
leaves the "why" to the room. Two things it will never do, because the game
itself can't: it will never name anyone's individual survival percentage —
those stay private permanently, not just until the tribunal — and it will
never claim a dark option was provably the smarter bet. If a prompt about the
hardest round comes up, the honest framing is that the cold option often
*felt* safer in the moment, not that it measurably was — resist the pull to
turn that into a verdict on whoever picked it.

## Quick reference — what the "next" button says

| Phase | Button reads |
|---|---|
| Lobby | Begin the briefing |
| Briefing | Start the warm-up / Start question 1 |
| Warm-up | Warm-up 2 |
| Question 1–8 | Question 2 … Question 9 |
| Question 9 | The final plea |
| Plea | Open the tribunal |
| Tribunal | Count the votes |

Whenever it's waiting on people rather than ready to move, it says so
instead: *Open without 2 choices*, *Open without 1 plea*, *Count without 3
votes*.
